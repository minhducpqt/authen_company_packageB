1. Làm sao để tạo một biểu mẫu (hợp đồng)?

  1. Vào Biểu mẫu → chọn giai đoạn Trước phiên → Hợp đồng dịch vụ.
  2. Bấm Tạo hợp đồng.
  3. Chọn dự án (mỗi dự án chỉ một hợp đồng — nếu đã có sẽ mở bản hiện có).
  4. Chọn Tỉnh/Thành và Xã/Phường bằng nút Tìm (gõ tên để lọc nhanh).
  5. Bấm Tạo / mở hợp đồng để vào màn hình biên tập.

Hệ thống tự điền tên UBND xã, địa điểm đấu giá, căn cứ QĐ/TB theo xã đã chọn. Bạn có thể bổ sung hoặc sửa trong editor.

2. Làm sao điền thông tin, kiểm tra và chốt văn bản?

  1. Panel trái: nhập / chỉnh thông tin hợp đồng (Bên A, Bên B, lô đất, căn cứ riêng…).
  2. Panel phải Xem trước: bấm Check để kiểm tra ô còn thiếu (đỏ bên trái, vàng trong preview).
  3. Bấm Lưu thường xuyên khi chỉnh sửa.
  4. Khi đủ thông tin, trên toolbar xem trước bấm Chốt → gõ tôi xác nhận → xác nhận.
  5. Sau chốt vẫn có thể Mở chốt (cũng cần gõ tôi xác nhận) nếu cần sửa lại.

3. Làm sao tải file HTML về máy?

  1. Mở hợp đồng trong editor.
  2. Bấm Tải HTML (thanh dưới panel trái) hoặc nút HTML trên toolbar xem trước.
  3. Trình duyệt tải file .html về máy — đây là bản in đúng định dạng hợp đồng.

Nên chốt văn bản trước khi tải để nội dung khớp bản cuối.

4. Làm sao mở HTML bằng Office và lưu thành DOCX?

  1. Tải file HTML như mục 3.
  2. Mở Microsoft Word (hoặc Word trong Microsoft 365).
  3. Chọn File → Open → Browse, chọn file .html vừa tải.
  4. Word hiển thị nội dung hợp đồng — kiểm tra lại bố cục, font Times New Roman 14pt nếu cần.
  5. Chọn File → Save As (Lưu thành) → định dạng Word Document (*.docx).
  6. Đặt tên file và lưu.

Lưu ý: Một số chi tiết CSS phức tạp có thể lệch nhẹ sau khi Word chuyển đổi — nên rà soát trang nền, bảng lô đất và khối chữ ký trước khi in.

5. Làm sao tra cứu biểu mẫu theo dự án?

  1. Từ trang Biểu mẫu, mục Theo dự án → Các biểu mẫu theo dự án.
  2. Chọn dự án trong dropdown → bấm Xem.
  3. Danh sách gom theo Trước / Trong / Sau phiên; bấm Mở để vào từng văn bản.
